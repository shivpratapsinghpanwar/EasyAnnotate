Phase 0 is complete: the wire format, the heavy-tool boundary, image orientation, and a measured canvas spike that holds 60fps with 300 shapes on a 4000×3000 image. None of those committed us to a user interface; all four settled a decision that would have been expensive to revisit.

Not built: the canvas editor itself, the SQLite store behind it, projects and image state, prediction import and review, and the SAM sidecar. That is Phases 1 to 3.

The one thing to fix first

Exporting to YOLO builds its class list from whatever labels happen to be present, sorted. Add one class mid-project and every index shifts — silently re-labelling every .txt already exported. The ordered label table in Phase 1 fixes it, and it gets a regression test on day one.
